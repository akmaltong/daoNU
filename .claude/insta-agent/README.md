# ИНСТА — агент для Инстаграма в Claude

13 скиллов для Claude, которые помогают вести Инстаграм на русском. Пишут рилсы, подписи, карусели и сторис, оценивают профиль, планируют неделю и чистят текст после ИИ.

Ничего не публикуют сами. Скиллы пишут, публикуешь ты.

Главное отличие от оригинала — 300 хуков Кирилла Потапова внутри: скилл рилса подбирает хук из базы под твою идею и оценивает его до съёмки.

## Команды

| команда | что делает |
| --- | --- |
| `/ig-reel` | Рилс из идеи: 3 хука из базы Кирилла с оценкой, сценарий, текст на экране, тайминг |
| `/ig-viral` | Ищет, что сейчас работает в твоей нише, и считает, во сколько раз ролик обогнал свой аккаунт |
| `/ig-caption` | Подпись: показывает, что видно в ленте до «ещё», проверяет призыв и хэштеги |
| `/ig-carousel` | Карусель: обложка, тексты слайдов и картинки 1080×1350 |
| `/ig-story` | Сторис на день и переход в директ |
| `/ig-profile` | Оценка профиля на 100 баллов и что исправить первым |
| `/ig-plan` | План недели: что, в каком формате и когда выкладывать |
| `/ig-human` | Чистит текст после ИИ: штампы, канцелярит, невидимые символы, не ломая русскую типографику |
| `/ig-comment` | Комментарии к чужим постам по делу |
| `/ig-reply` | Ответы в комментариях под своим постом |
| `/ig-dm` | Директ по кодовому слову: выдача, первое сообщение, коллаб, два напоминания |
| `/ig-repurpose` | Эфир, вебинар или пост → серия рилсов и каруселей |
| `/ig-audit` | Разбор того, что уже выложено: что сработало и почему |

## Голос автора

Скиллы пишут твоим голосом, если заполнить `templates/voice.md`. Проще всего: пришли Claude три своих рилса или подписи и напиши «заполни мой voice.md по ним». Файл лежит в `~/.claude/instagram/voice.md`.

## Нужен Claude Code

Скиллы рассчитаны на Claude Code: оценка хуков по базе, тайминг, проверка подписи и чистка текста — это скрипты, в обычном чате они не запускаются, и Claude начнёт оценивать на глаз. Без Claude Code годится только `/ig-caption`: его правила записаны словами.
