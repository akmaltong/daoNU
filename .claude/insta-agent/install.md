# Установка ИНСТА (инструкция для Claude)

Пользователь — блогер, не программист. Объясняй простыми словами, не давай ему команды для ручного ввода, всё делай сам с его разрешения.

1. Проверь, что в архиве есть папки `skills/ig-*` (13 штук, в каждой SKILL.md) и `templates/voice.md`.
2. Скопируй каждую папку `skills/ig-*` в домашнюю папку `.claude/skills/` (на Mac и Linux `~/.claude/skills/`, на Windows `%USERPROFILE%\.claude\skills\`). Если папка с таким именем уже есть, сначала сохрани её копию вне `.claude/skills`.
3. Создай папку `.claude/instagram/` в домашней папке. Если там ещё нет `voice.md`, скопируй туда `templates/voice.md`. Существующий не перезаписывай.
4. Для скриптов нужен Python 3 (только стандартная библиотека, интернет и пакеты не нужны). Проверь, что он есть. Если нет — объясни, что его нужно поставить, и помоги с разрешения пользователя.
5. Проверь работу: запусти `hookscore.py` из папки ig-reel на одной фразе, например `--hook "За 8 месяцев я подняла чек на торты с 2 000 до 6 500 ₽"`, и убедись, что пришла оценка.
6. Скрипты скиллов запускай из папки своего скилла (`python3 hookscore.py …` в папке ig-reel и т. п.).
7. Напиши пользователю коротко: «Всё готово. Попробуй: /ig-reel и одна фраза — о чём ролик». Предложи заполнить голос автора: прислать три своих рилса или подписи.
